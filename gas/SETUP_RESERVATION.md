# 予約フォームの設定手順（GAS ＋ Discord通知）

サイト内の予約フォームを動かすための準備です。**所要 10〜15分**。
一度設定すれば、あとは受付日時を変えるだけで使い回せます。

---

## 0. 書き込み先のシートについて

既定では、スプレッドシート内の **`Form_Responses`** シート（＝これまでのフォーム回答シート）の
いちばん下に、**同じ列の並びで1行ずつ追記**されます。

| 列 | 内容 |
|---|---|
| A | タイムスタンプ |
| B | お名前（VRC表示名） |
| C | 撫でる、撫でられる |
| D | 苦手はありますか |
| E | ご希望の主な診察方法 |
| F | プレイ環境 |
| G | XプロフィールURL |

- **見出し行はすでにあるものをそのまま使います**（勝手に書き換えません）
- 別のシートに分けたい場合は、`reservation.gs` の先頭にある
  `const SHEET_NAME = 'Form_Responses';` を好きなシート名に変えてください
  （そのシートが無ければ自動で作り、見出しも自動で付きます）

---

## 1. 応募データを保存するスプレッドシートを作る

1. [Googleスプレッドシート](https://sheets.new) を新規作成
2. 名前を「リルレオクリニック 応募一覧」などに変更
3. **このスプレッドシートは共有しないでください**（個人情報が入るため、自分だけが見られる状態のままに）

---

## 2. スクリプトを貼り付ける

1. スプレッドシートのメニュー **拡張機能 → Apps Script**
2. 最初から入っているコード（`function myFunction() {}`）を**全部消す**
3. `reservation.gs` の中身を**すべてコピーして貼り付け**
4. 💾 保存（Ctrl + S）

---

## 3. Discord通知の設定（⑦）

### 3-1. Discord側で Webhook を作る
1. 通知を受け取りたい **運営用チャンネル** を開く
   - ⚠ **必ず運営メンバーだけが見られる非公開チャンネル**にしてください（応募者の個人情報が流れます）
2. チャンネル名の横の ⚙️（チャンネルの編集）→ **連携サービス** → **ウェブフックを作成**
3. **ウェブフックURLをコピー**

### 3-2. Apps Script に登録する
1. Apps Scriptの左メニュー ⚙️ **プロジェクトの設定**
2. 下の方の **スクリプト プロパティ** → **スクリプト プロパティを追加**
3. 以下を追加して**保存**

| プロパティ | 値 |
|---|---|
| `DISCORD_WEBHOOK_URL` | さきほどコピーしたウェブフックURL |

> 💡 Webhook URL はここに入れることで**サイトのコードには出ません**。
> （サイト側に書くと誰でも見られて、いたずら投稿に使われてしまいます）

---

## 4. 受付日時を決める（任意・あとから何度でも変更可）

同じ **スクリプト プロパティ** に、必要なら追加します。

| プロパティ | 値の例 | 意味 |
|---|---|---|
| `OPEN_AT` | `2026-08-05 21:00` | この日時より前は受け付けない |
| `CLOSE_AT` | `2026-08-10 23:59` | この日時より後は受け付けない |

- **未設定なら「いつでも受付」**になります
- 形式は `YYYY-MM-DD HH:MM`（時刻は省略可）

> 📌 サイトの表示（「受付開始まで」「受付終了しました」）は
> `reservation-config.js` で切り替えます。**実際に受け付けるかどうかはこちらのGAS側が最終判断**なので、
> 早く送信しようとしても弾かれます。

---

## 5. ウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ**
2. ⚙️（種類の選択）→ **ウェブアプリ**
3. 設定を以下にする

| 項目 | 設定 |
|---|---|
| 説明 | 予約受付（任意） |
| 次のユーザーとして実行 | **自分** |
| アクセスできるユーザー | **全員** ← ここ重要 |

4. **デプロイ** をクリック
5. 初回は「承認が必要です」と出るので、**アクセスを承認**
   - 「このアプリは確認されていません」と出たら → **詳細** → **（プロジェクト名）に移動** → 許可
6. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）を**コピー**

> ⚠ 「アクセスできるユーザー」が**全員**でないと、サイトから送信できません。
> （「全員」でも、できるのは*送信*だけです。応募内容を読み出す機能はありません）

---

## 6. サイトに URL を設定する

`reservation-config.js` を開き、`endpoint` にコピーしたURLを貼り付けます。

```js
const LILLEO_RESERVATION = {
    endpoint: 'https://script.google.com/macros/s/……/exec',   // ← ここ
    ...
};
```

---

## 7. テストする

1. サイトの予約ページを開いて、テスト内容で送信
2. **スプレッドシートに1行増える**ことを確認
3. **Discordに通知が届く**ことを確認
4. テスト行はスプレッドシートから削除してOK

---

## あとから変更したいとき

| やりたいこと | どこを変える |
|---|---|
| 受付開始・終了日時を変える | スクリプト プロパティの `OPEN_AT` / `CLOSE_AT` |
| サイトの表示（受付中／準備中）を変える | `reservation-config.js` |
| 通知先チャンネルを変える | スクリプト プロパティの `DISCORD_WEBHOOK_URL` |
| 質問項目を変える | `reservation.gs` の `FIELDS` と、サイトのフォーム（要相談） |

> スクリプトを書き換えたときは、**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ**
> をしないと反映されません（URLは変わりません）。

---

## 個人情報の扱いについて（このしくみの設計）

- 応募内容が保存されるのは、**あなたのスプレッドシートだけ**です
- Discordの通知先は**運営専用の非公開チャンネル**にしてください
- サイト側のコードに含まれるのは**送信先URLのみ**で、Webhook URLやスプレッドシートは含まれません
- 保存済みの応募内容を外部から読み出す機能は**ありません**（書き込み専用）
- ブラウザ側に個人情報は保存しません（入力内容は送信後に破棄されます）
- 応募者には、フォーム上で「用途・保存先・任意項目」を明示しています
